# R.E.C.A.L.L.
**R**epetition **E**ngine for **C**ode, **A**lgorithms & **L**ogic **L**earning 

SRS for learning: Coding, Algorithms, Logic, Math.

Project born out of curiosity to apply SRS concepts to learning code, because i've used SRS for ages learning languages and i noticed my language learning progress and my theoretical progress is much much faster than my coding progress, even if i spend more time coding than doing other things. Also current systems arent gamified at all ! 
Why should learning to code be an harder problem than it actually is... is it gatekeeping? Probably not, after all, the open-source community has everything available. Then what is the problem? Consistency? Maybe; i think the problem is in the **logistics** itself, so many ways to learn, so many concepts to learn, at this point in time (2026) there is so much stuff to learn about programming, informatics and coding in general, that people cant possibly learn it all in multiple lifetimes! BUT at the same time, learning these things has never been harder: 
- what site to use;
- what roadmap to follow;
- what projects to make;
- what language to use 
- etc....  
So, what is the endgame here? My plan is to make a simpler, logistical solution to this issue, with the sole purpose of helping people(me included) to learn how to code.
